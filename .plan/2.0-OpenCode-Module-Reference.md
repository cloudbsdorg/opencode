## 1. CLI Module

**Location:** `packages/opencode/src/cli/`

### 1.1 Entry Point

**File:** `src/index.ts`

Main CLI entry point that:
- Parses command-line arguments using yargs
- Initializes logging and environment
- Routes to appropriate command handlers

**Key Exports:**
```typescript
// Command handlers
import { RunCommand } from "./cli/cmd/run"
import { GenerateCommand } from "./cli/cmd/generate"
import { ServeCommand } from "./cli/cmd/serve"
```

interface Agent {

## 3. Session Module

**Location:** `packages/opencode/src/session/`

### 3.1 Session Management

**File:** `session.ts`

Manages the conversation session lifecycle.

**Key Interface:**
```typescript
interface Session {
  id: string
  createdAt: Date
  messages: Message[]
  
  addMessage(message: Message): void
  compact(): Promise<void>
  persist(): Promise<void>
}
```

### 3.2 Message Handling

**Files:**
- `message.ts` — Basic message handling
- `message-v2.ts` — Enhanced message processing with tool support

### 3.3 Prompt Construction

**File:** `prompt.ts`

Builds prompts for LLM calls based on:
- System instructions
- Conversation history
- Available tools
- Context files

### 3.4 Session Compaction

**File:** `compaction.ts`

Handles long conversation compaction to stay within LLM context limits.

**Compaction Strategies:**
1. Summarize old messages
2. Remove redundant context
3. Preserve critical decisions

### 3.5 LLM Interaction

**File:** `llm.ts`

Handles communication with AI providers.

**Key Functions:**
```typescript
// Generate completion
function generate(prompt: Prompt, options: GenerateOptions): Promise<Completion>

// Stream completion
function generateStream(prompt: Prompt, options: GenerateOptions): AsyncIterable<Chunk>
```

### 3.6 Database Schema

**File:** `session.sql.ts`

Drizzle ORM schema for session persistence.

## 6. Storage Module

**Location:** `packages/opencode/src/storage/`

### 6.1 Database Interface

**File:** `db.ts`

Main database interface using Drizzle ORM.

```typescript
interface Database {
  // Query operations
  query<T>(sql: string, params?: any[]): Promise<T[]>
  
  // Transaction support
  transaction<T>(fn: (tx: Transaction) => Promise<T>): Promise<T>
}
```

### 6.2 Database Adapters

| Platform | File | Implementation |
|----------|------|----------------|
| Bun | `db.bun.ts` | `bun:sqlite` |
| Node.js | `db.node.ts` | `node:sqlite` + drizzle |
| FreeBSD | `db.node.ts` | `node:sqlite` + drizzle |

**Node.js Adapter:**
```typescript
import { DatabaseSync } from "node:sqlite"
import { drizzle } from "drizzle-orm/node-sqlite"

export function init(path: string) {
  const sqlite = new DatabaseSync(path)
  return drizzle({ client: sqlite })
}
```

### 6.3 Schema Definitions

Drizzle schema definitions for:
- Sessions
- Messages
- Files
- Tool calls

### 6.4 JSON Migration

**File:** `json-migration.ts`

Utilities for migrating JSON data to SQLite.

### 6.5 Storage Utilities

**File:** `storage.ts`

High-level storage operations.

## Appendix A: Common Patterns

### A.1 Importing Platform-Specific Code

```typescript
// Import the correct adapter based on platform
import { adapter } from "#hono"
```

### A.2 Database Operations

```typescript
import { Database } from "@/storage/db"

const db = Database.init("/path/to/db.sqlite")
await db.query("SELECT * FROM sessions")
```

### A.3 PTY Operations

```typescript
import { spawn } from "#pty"

const proc = spawn("bash", [], {
  cwd: "/path/to/dir",
  env: { ...process.env }
})

proc.onData((data) => {
  console.log(data)
})

proc.write("echo hello\n")
proc.kill()
```
