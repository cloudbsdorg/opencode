## 1. Executive Summary

### 1.1 Goal

Port OpenCode to run natively on FreeBSD systems, removing the Bun runtime dependency for FreeBSD builds while maintaining cross-platform compatibility with Linux, macOS, and Windows.

### 1.2 Strategy

Leverage existing Node.js implementations for FreeBSD, as the codebase already has:
- Conditional import infrastructure
- Node.js adapters for PTY, server, and database
- Build targets for FreeBSD

### 1.3 Key Changes Required

1. **Package.json** — Already has FreeBSD conditional exports ✓
2. **Build script** — Already has FreeBSD targets ✓
3. **bunfs root** — Already set to `/usr/local/lib/opencode/` ✓
4. **Verification** — Need to verify node-pty, db, and server work on FreeBSD
5. **CI/CD** — Add FreeBSD CI runner
6. **Testing** — End-to-end testing on FreeBSD

## 7. Installation Guide

### 7.1 Quick Start

On a FreeBSD system with Bun installed:

```bash
# Clone the repository
git clone https://github.com/cloudbsdorg/freebsd-src-build-emulation.git
cd freebsd-src-build-emulation

# Build for FreeBSD
cd packages/opencode
bun install
bun run script/build.ts --baseline --single

# Install system-wide (requires root)
sudo make install

# Or install to ~/.local
make install PREFIX=~/.local

# Run opencode
opencode
```

### 7.2 Using the Install Script

The install script automatically detects where it can install and creates necessary directories.

```bash
# Auto-detect best location (default)
./install.sh

# System-wide install
sudo ./install.sh --system

# User-local install
./install.sh --user

# Custom prefix
./install.sh --prefix /opt/opencode
```

### 7.3 Makefile Targets

| Target | Description |
|--------|-------------|
| `make build` | Build FreeBSD binary |
| `make install` | Install to PREFIX (default: /usr/local) |
| `make install-auto` | Auto-detect best location and install |
| `make install-system` | Install to /usr/local (requires root) |
| `make install-user` | Install to ~/.local |
| `make configure-path` | Configure PATH in shell profile |
| `make uninstall` | Uninstall from PREFIX |
| `make clean` | Remove build artifacts |
| `make test` | Run tests |
| `make help` | Show help |

### 7.4 Auto-Detection Features

Both the install script and Makefile's `install-auto` target:

1. **Check permissions**: Test if `/usr/local/bin` and `/var/db` are writable
2. **Create directories**: Create `~/.local/bin`, `~/.local/lib`, `~/.local/share` if needed
3. **Fall back gracefully**: If system-wide fails, try user-local installation
4. **Provide helpful messages**: Suggest adding to PATH for user-local installations

### 7.5 PATH Configuration

For user-local installations (`~/.local`), both scripts automatically:

1. **Detect user's shell**: Identifies bash, zsh, fish, tcsh/csh, or sh
2. **Check existing PATH**: Scans shell profiles for existing `~/.local/bin` entries
3. **Add PATH entry**: Appends the appropriate export to the profile file:
   - **bash/zsh**: `export PATH="$HOME/.local/bin:$PATH"`
   - **fish**: `fish_add_path $HOME/.local/bin`
   - **tcsh/csh**: `setenv PATH "$HOME/.local/bin:$PATH"`
4. **Notify user**: Provides shell-specific reload instructions

## Appendix A: FreeBSD-Specific Considerations

### A.1 Installation Path

FreeBSD packages typically install to `/usr/local/`. The bunfs root is set to `/usr/local/lib/opencode/` to align with this convention.

### A.2 Shell Support

FreeBSD uses `/bin/sh` as the default shell. The PTY implementation should handle:
- `bash` (if installed from ports/packages)
- `sh` (default)
- `zsh` (if installed from ports/packages)

### A.3 node-pty Prebuilds

node-pty provides FreeBSD prebuilds for:
- FreeBSD 12.x (x64)
- FreeBSD 13.x (x64, arm64)
- FreeBSD 14.x (x64, arm64)

### A.4 Native Modules

FreeBSD requires native modules to be compiled against FreeBSD libraries. The `@lydell/node-pty` package includes prebuilt binaries for FreeBSD.
